パートナーと共有されるデータ
独自の目的で当社のビジネスパートナーと個人データを共有したくない場合は、その旨を当社に電子メールで送信することができます。

マーケティングに関するメール
このような通信を受け取りたくない場合は、アカウントにログインし、メーリング リストからオプトアウトすることで、メーリング リストから自分自身を削除することができます。

クッキー
当社および当社のビジネス パートナーは、Cookie を使用してお客様のオンライン サービスの使用に関する情報を収集します。 Cookie は、当社がお客様のコンピュータまたはその他のデバイスに送信する非常に小さなファイルで、将来お客様が当社のサイトにアクセスしたときにアクセスできます。 Cookie は、お客様が誰であるか、およびお客様の訪問に関するその他の情報を記憶するのに役立ちます。 ほとんどの主要な Web サイトでは Cookie が使用されています。 Cookie がないと、多くのブラウザーが新しい Cookie の受け入れを中止するよう通知するため、当社の Web サイトの属性を十分に活用できない可能性があります。

データの不正確さとアクセス
お客様は、当社 Web サイト上のアカウントを通じて誤った情報を修正または更新することができ、また当社がお客様に関して保管している一部のデータのコピーを取得することもできます。 ご自身の個人情報が間違っていると思われる場合は、当社にご連絡いただくことで、その不正確さを修正するよう求めることができます。 当社のプライバシー通知の「当社への連絡方法」セクションをご覧ください。

他の Web サイトへのリンク
皆様の知識と便宜のために、当社の Web サイトには他の Web サイトへのリンクが含まれる場合があります。 当社が含む Web サイトのリンクは、ペンタクレバ コンセプト ショッピング モールと提携していない会社によって管理されている場合があります。 私たちが含める Web サイトには、独自のプライバシーに関する通知があるはずです。 私たちが提携していないウェブサイトのコンテンツについては責任を負わないため、私たちのものと同様にレビューする必要があります。

データの転送
当社は、お客様に関する個人データを含む場合、米国を含むお客様が拠点を置く国外でデータを処理する場合があります。 これは米国の Web サイトであるため、お客様の情報のセキュリティとプライバシーを保護するなどの米国の法律が適用されます。 プライバシー通知に記載されているように、当社はすべての個人データを保存します。

インターナショナルチェックアウト
当社は eShopWorld と協力して、海外の特定の目的地に製品を販売および配送しています。 eShopWorld がサポートする国に配送する場合は、当社のサービスから「powered by eShopWorld」の共同ブランドのチェックアウト サービスに移動します。 eShopWorld のプライバシー ポリシーは、当社のポリシーではなく、支払い情報など、そのサイトで直接提供する情報に適用されます。 さらに、お客様が eShopWorld のチェックアウト サイトにアクセスすると、お客様が eShopWorld から当社の製品を購入しやすくするために、お客様とお客様の注文に関する情報が eShopWorld と共有されます。 eShopWorld のプライバシー慣行については、eShopWorld のプライバシー ポリシーをご覧ください。

個人データの保護方法
当社は、収集した個人データを保護するために安全措置を講じています。 データの電子通信は完全に安全ではないことをご理解ください。 当社の Web サイトにアクセスし終わったら、アカウントからサインアウトしてブラウザを終了することをお勧めします。 また、アカウント情報を他の人と共有しないでください。 ユーザー名やパスワードなどのアカウント情報を電子メールで尋ねることは決してないことに注意してください。 セキュリティの詳細については、以下のセキュリティ ポリシーをご覧ください。
